# 设备使用时间追踪系统 - 项目总体概述

## 1. 项目简介

设备使用时间追踪系统是一个实时监控和记录用户设备使用情况的综合平台。系统通过桌面客户端采集用户的行为数据,通过服务器端进行处理和存储,并通过Web前端实时展示给授权的查看者。

## 2. 系统架构

### 2.1 整体架构

```
┌─────────────────┐
│  Windows客户端   │ (Python + PyQt)
│  数据采集模块     │
└────────┬────────┘
         │ HTTP/WebSocket (每秒增量上传)
         ▼
┌─────────────────┐
│   后端服务       │ (Spring Boot)
│  - 数据接收      │
│  - 实时推送      │
│  - 数据归档      │
└────┬─────┬──────┘
     │     │
     │     └─────── WebSocket推送
     │
     ▼ REST API
┌─────────────────┐
│  Web前端        │ (Vue3 + TypeScript)
│  - 实时展示      │
│  - 历史查询      │
│  - 用户管理      │
└─────────────────┘
```

### 2.2 数据流架构

```
客户端采集 → 实时上传(增量) → Redis(热数据,1周) → MySQL(冷数据,永久)
                                    ↓
                              WebSocket推送
                                    ↓
                              前端实时展示
```

## 3. 技术栈

### 3.1 客户端
- **语言**: Python 3.10.19
- **UI框架**: PyQt5
- **系统监控**: 
  - pywin32 (Windows API调用)
  - EVENT_SYSTEM_FOREGROUND (窗口切换监听)
  - pynput (键盘鼠标监听)

### 3.2 后端
- **框架**: Spring Boot 3.5.16
- **数据库**: 
  - Redis (热数据缓存)
  - MySQL (冷数据持久化)
- **通信**: WebSocket (实时推送)
- **认证**: JWT Token

### 3.3 前端
- **框架**: Vue 3 + TypeScript
- **UI组件库**: Element Plus / Ant Design Vue
- **状态管理**: Pinia
- **路由**: Vue Router
- **HTTP客户端**: Axios

## 4. 核心功能模块

### 4.1 数据采集模块 (客户端)
- 窗口焦点监听
- 应用使用时长统计
- 键盘敲击计数
- 鼠标点击计数
- 鼠标移动距离追踪
- 鼠标滚轮滚动距离追踪

### 4.2 数据传输模块
- 增量数据上传 (每秒一次)
- WebSocket双向通信
- 断线重连机制

### 4.3 数据存储模块
- Redis热数据存储 (近7天)
- MySQL冷数据存储 (历史数据)
- 自动数据归档机制
- 数据压缩策略

### 4.4 实时推送模块
- WebSocket连接管理
- 多查看者订阅机制
- 实时数据广播

### 4.5 前端展示模块
- 实时状态展示
- 应用使用时长可视化
- 历史数据查询 (日历切换)
- 用户管理界面
- 秘钥管理

## 5. 数据流转说明

### 5.1 实时数据流
1. 客户端每秒采集增量数据
2. 通过HTTP POST上传到后端
3. 后端更新Redis中的热数据
4. 通过WebSocket推送给所有订阅该用户的查看者
5. 前端实时更新展示

### 5.2 历史数据流
1. 用户通过前端选择历史日期
2. 前端发送REST API请求
3. 后端查询MySQL冷数据
4. 返回完整历史数据汇总
5. 前端展示历史数据

### 5.3 数据归档流
1. 定时任务检查Redis中超过7天的数据
2. 将数据迁移到MySQL
3. 从Redis中删除已归档数据
4. 保留数据索引以便快速查询

## 6. 安全机制

### 6.1 用户认证
- 邮箱 + 密码注册登录
- JWT Token认证
- Token过期自动刷新

### 6.2 数据访问控制
- 秘钥机制实现数据共享
- 秘钥全局唯一,可重新生成和作废
- 查看者无需注册即可通过秘钥查看

### 6.3 数据安全
- 密码加密存储
- 敏感数据传输加密
- 防SQL注入
- XSS防护

## 7. 部署架构

### 7.1 开发环境
- 客户端: Windows开发机
- 后端: 本地Spring Boot服务
- 前端: 本地Vue开发服务器
- 数据库: 本地MySQL + Redis

### 7.2 生产环境
- 客户端: Windows客户端打包为exe
- 后端: 云服务器部署Spring Boot
- 前端: 静态资源部署到Nginx/CDN
- 数据库: 云数据库服务

## 8. 扩展性设计

### 8.1 WebSocket扩展性
- 支持未来添加更多实时功能
- 如:实时通知、多人协作、评论系统等

### 8.2 数据存储扩展性
- 热数据/冷数据分离架构
- 支持未来数据量增长
- 可扩展为分布式存储

### 8.3 客户端扩展性
- 模块化设计
- 可扩展支持更多操作系统
- 可添加更多监控维度

## 9. 项目优势

1. **实时性强**: 2秒内延迟,WebSocket推送
2. **数据完整**: 永久保存,热冷数据分离
3. **易于分享**: 秘钥机制,无需注册即可查看
4. **跨平台**: 客户端Windows,前端跨浏览器
5. **高扩展**: WebSocket架构支持未来功能扩展

## 10. 项目目标用户

- **主要用户**: 需要监控自己设备使用情况的个人用户
- **查看者**: 通过秘钥查看他人使用情况的用户(如家长、团队负责人等)
- **使用场景**: 
  - 个人时间管理
  - 团队工作监控
  - 家庭设备使用监控
