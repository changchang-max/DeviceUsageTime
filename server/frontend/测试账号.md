## 📝 使用说明

### 方式1: 直接登录（推荐）

1. 访问登录页面: http://localhost:3000/login
2. 输入邮箱: `test@example.com`
3. 输入密码: `Test123456`
4. 点击"登录"按钮
5. 自动跳转到监控页面

### 方式2: 使用秘钥查看

1. 访问秘钥查看页面: http://localhost:3000/view
2. 输入秘钥: `TestKey123456789`
3. 点击"查看"按钮
4. 自动跳转到监控页面（只读模式）

### 方式3: 直接访问监控页面

访问: http://localhost:3000/monitor?key=TestKey123456789

## ✨ 测试功能

登录成功后，你可以测试以下功能：

### 1. 实时监控页面
- 查看实时数据展示
- 观察应用使用时长图表
- 查看统计数据卡片
- 测试WebSocket连接状态

### 2. 个人中心
- 访问: http://localhost:3000/profile
- 查看用户信息
- 测试秘钥管理功能：
  - 复制秘钥
  - 重新生成秘钥

  - 复制分享链接

### 3. 历史数据查询
- 在监控页面左侧日历中选择日期
- 查看历史数据（Mock数据会自动生成）

### 4. 退出登录
- 点击右上角"退出登录"
- 测试退出功能

## 🎯 Mock数据特点

### 实时数据
- 每次刷新会有轻微变化（模拟实时更新）
- 包含4个应用的使用数据：
  - Chrome (活跃)
  - VSCode (已关闭)
  - WeChat (已关闭)
  - QQ音乐 (已关闭)

### 历史数据
- 任何日期都会返回模拟数据
- 包含3个应用的历史汇总：
  - Chrome
  - VSCode
  - WeChat

### 日期标记
- 每个月会随机生成一些有数据的日期
- 在日历中显示为带圆点的日期

## 🔄 注册新账号

如果想测试注册功能：

1. 访问注册页面: http://localhost:3000/register
2. 输入任意邮箱（不能是 test@example.com）
3. 点击"发送验证码"
4. **在浏览器控制台查看验证码**（F12打开控制台）
   - 会显示类似: `[Mock] 验证码已发送到 your@email.com: 123456`
5. 输入验证码和密码
6. 点击"注册"
7. 注册成功后跳转到登录页面

## 🚨 注意事项

1. **数据不会持久化** - 刷新页面后所有注册的账号和数据都会重置
2. **测试账号永久有效** - `test@example.com` 始终可以登录
3. **验证码在控制台** - 注册时需要在浏览器控制台查看验证码
4. **WebSocket需要真实后端** - Mock环境无法测试WebSocket实时推送

## 📞 问题反馈

如果遇到问题：
1. 检查浏览器控制台是否有错误
2. 查看控制台的Mock日志
3. 确认是否正确输入了测试账号信息
4. 尝试刷新页面重新登录
