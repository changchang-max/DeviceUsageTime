# 测试说明(已对接真实后端)

> Mock 数据已移除,前端所有接口直接对接后端 Spring Boot。
> 测试前请先启动后端(`http://localhost:8080`)并保证 MySQL、Redis 可用。

## 📝 使用说明

### 方式1: 注册/登录

1. 访问注册页面: http://localhost:3000/register
2. 输入邮箱,点击"发送验证码"——验证码会发送到该邮箱(后端邮件服务),**不会在控制台显示**
3. 输入验证码和密码完成注册
4. 注册成功后跳转到登录页面,使用刚注册的邮箱密码登录
5. 登录成功自动跳转到监控页面

### 方式2: 使用秘钥查看(分享链接)

1. 登录后进入个人中心 http://localhost:3000/profile
2. 复制"分享链接"(含 URL 编码后的秘钥)
3. 在无痕/未登录浏览器打开该链接,即可只读查看实时数据
4. 也可以在秘钥查看页面手动输入秘钥: http://localhost:3000/view

## ✨ 测试功能

1. **实时监控**: 需本机运行桌面客户端持续上传数据,才能看到实时数据与 WebSocket 推送
2. **历史数据**: 日历中选择有圆点标记的日期(有数据才显示),无数据的日期显示空状态
3. **个人中心**: 查看用户信息、复制秘钥/分享链接、重新生成秘钥、作废秘钥
4. **秘钥查看者模式**: 只读查看他人数据,无法修改

## 🚨 注意事项

1. **数据来自真实后端** - 实时数据由桌面客户端上传,历史数据由后端数据库归档产生;无数据时页面为空状态
2. **验证码在邮箱中** - 需要能收到后端发送的邮件(需正确配置后端邮件服务)
3. **WebSocket 代理** - 开发模式下 `/ws` 由 Vite 代理到后端,后端会推送实时数据
4. **秘钥含特殊字符** - 复制分享链接时前端已做 URL 编码,请直接复制完整链接

## 📞 问题反馈

如果遇到问题:
1. 检查浏览器控制台与 Network 标签页是否有错误
2. 确认后端已启动、接口请求已返回
3. 尝试刷新页面重新登录
