# 前端项目启动指南

## 问题诊断

如果页面什么都没有显示，请按以下步骤检查：

## 步骤1: 安装依赖

```bash
cd d:\Code\Projects\DeviceUsageTime\server\frontend
npm install
```

等待依赖安装完成（可能需要几分钟）。

## 步骤2: 启动开发服务器

```bash
npm run dev
```

应该会看到类似输出：
```
VITE v5.0.11  ready in 1234 ms

➜  Local:   http://localhost:3000/
➜  Network: http://192.168.x.x:3000/
```

## 步骤3: 打开浏览器

访问 http://localhost:3000

应该会自动跳转到登录页面 `/login`

## 常见问题排查

### 1. 页面空白
**检查浏览器控制台（F12）**，查看是否有错误：

#### 错误: "Cannot find module"
- 确保已运行 `npm install`
- 删除 `node_modules` 文件夹，重新安装

#### 错误: 路由相关错误
- 确保所有 `.vue` 文件都存在
- 检查 `src/views/` 目录下是否有所有页面组件

### 2. 端口被占用
如果3000端口被占用，修改 `vite.config.ts`：
```typescript
server: {
  port: 3001,  // 改为其他端口
  host: true,
  open: true
}
```

### 3. Mock数据不工作
检查 `mock/` 目录是否存在以下文件：
- `auth.ts`
- `user.ts`
- `data.ts`

### 4. Element Plus样式未加载
确保 `main.ts` 中有：
```typescript
import 'element-plus/dist/index.css'
```

## 快速验证

运行开发服务器后，在浏览器控制台输入：
```javascript
// 检查Vue是否加载
console.log(window.__VUE__)

// 检查路由是否正常
console.log(window.location.pathname)
```

## 预期行为

1. 访问 `http://localhost:3000/` 
2. 自动重定向到 `/login`
3. 显示登录页面（紫色渐变背景）
4. 可以点击"立即注册"跳转到注册页面

## 测试功能

### 注册流程
1. 点击"立即注册"
2. 输入邮箱，点击"发送验证码"
3. **控制台会显示验证码**，例如：`[Mock] 验证码已发送到 user@example.com: 123456`
4. 输入验证码和密码
5. 点击注册

### 登录流程
1. 输入邮箱和密码
2. 点击登录
3. 自动跳转到监控页面
