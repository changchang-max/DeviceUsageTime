# 数据上传接口测试程序

## 功能说明

这是一个用于测试 `POST /api/data/upload` 接口的Python测试工具。

## 依赖安装

```bash
pip install requests
```

## 使用方法

### 1. 基本运行

```bash
python test_upload.py
```

### 2. 测试模式

程序提供3种测试模式：

#### 模式1: 使用已有Token直接测试
- 适用于已有有效Token的情况
- 直接输入Token即可开始测试
- 会执行4个测试场景

#### 模式2: 先登录获取Token再测试
- 输入邮箱和密码
- 自动登录获取Token
- 执行完整的测试场景

#### 模式3: 持续上传测试
- 模拟客户端每秒上传的场景
- 可自定义上传间隔和次数
- 适合压力测试和长时间运行测试

## 测试场景

### 场景1: 正常上传
- 包含2个应用数据
- 包含完整的统计数据
- 预期返回200

### 场景2: 空applications列表
- applications为空数组
- 仍包含统计数据
- 预期返回200

### 场景3: statistics为None
- 包含应用数据
- 不包含统计数据
- 预期返回200

### 场景4: 多个应用数据
- 包含4个应用的数据
- 包含完整统计数据
- 预期返回200

## 配置选项

可在代码中修改以下配置:

```python
BASE_URL = "http://localhost:8080"  # 服务器地址
```

## 注意事项

1. 确保后端服务已启动
2. 确保Redis服务已启动
3. Token有效期默认24小时
4. 持续上传测试会产生大量数据，注意Redis容量

## 错误处理

程序会捕获并显示以下错误:
- HTTP错误(401, 400, 500等)
- 网络连接错误
- JSON解析错误
- 其他异常
